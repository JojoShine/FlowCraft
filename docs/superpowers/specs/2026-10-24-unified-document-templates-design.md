# 统一文档与 AI 模板

用户已确认：文档中心内设文档/模板两个页签，模板支持 AI 扩写；右侧助手生成后预览，确认再应用到 Tiptap 正文。原有模板和产物保留；UI 沿用项目组件、主题、字号和间距。仅本地开发验证，沿用当前会话顺序实现、最后独立评审。

统一预制模板与个人模板的选择入口。预制模板保留现有章节；新个人模板使用版本化正文 JSON 和写作要求保存到既有 Template.content（fileType=flowcraft），无需改数据库。原 HTML/Word/Markdown 模板保持原记录和原编辑器，可转换为新文档；不覆盖迁移。正文可另存为模板，跨项目资源引用转为填写占位，块 ID 重新生成。

新建文档可直接编辑或打开助手扩写。助手基于当前已保存正文结构、用户文字和 MD/TXT/DOCX/PDF 附件生成 Markdown 建议，复用现有 AI 和附件解析。生成端点校验所有权和基准版本，只返回预览，绝不写文档或产物。旧产物与原有聊天保存产物入口保留。

预览确认按钮明确“确认替换正文”，提示原文在历史版本中；原有媒体在旧版本保留。应用前比较当前正文/标题快照和版本，再检查服务端版本，变化时拒绝旧预览。确认后通过现有保存队列、版本冲突及历史流程保存。生成、取消、失败均不修改正文。路由或账号切换终止旧会话，项目切换不得改变正在扩写的目标文档。

验证：入口兼容与模板 ID/资源隔离；预览无写入、所有权、版本冲突、附件/模型错误；确认应用前后正文与历史、生成中继续编辑、取消、主题、现有编辑/任务模式回归。外部模型在隔离运行时禁用，使用模拟响应验证契约，不读取生产凭据。
