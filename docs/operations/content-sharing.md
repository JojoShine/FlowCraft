# 文档与绘图分享

所有者在文档或绘图编辑页点击“分享”，开启后复制公开链接。打开设置前会等待当前编辑内容保存；保存失败时不会继续开启分享。访客无需登录，仅能查看最新已保存内容，不显示编辑、历史版本或 AI 助手。

文档中的图片、附件和内嵌绘图随文档一同开放。内嵌图保留“跟随最新”或“固定版本”规则，切回分享页面时重新读取。关联文档不自动开放。公共文件请求只允许当前内容实际引用的文件，不提供整个项目或任意历史版本的读取权限；画布已删除元素和未使用文件不进入公开响应。

关闭分享后旧链接失效。再次开启生成新的链接；移入回收站同时关闭分享，恢复内容不会自动恢复旧链接。已加载或下载的副本无法从访客设备收回。

文档中的 Markdown 表格导入后成为可编辑表格。在编辑模式下点击任意单元格，正文上方工具栏显示“添加行 / 添加列 / 删除表格”。点击“删除表格”删除整张表，仍可用撤销恢复；自动保存后刷新保持删除结果。

本次迁移仅向 ContentDocument、Drawing 添加可空的 shareToken 字段及唯一索引，不清空数据库，不变更 MinIO 存储配置。生产发布仍按现有 GitHub CI → GHCR → Release → 备份和迁移流程执行。
