# Tiptap 3 本地单页样板验证

日期：2026-10-23。范围：独立样板；未访问或更新线上，未替换现有编辑器。

## 入口与范围

- 文档中心的“编辑器样板”，或 `/flowcraft/documents/sample`，选择项目后创建独立文档。
- 样板地址 `/flowcraft/documents/:id/sample`，复用原 Sidebar、Topbar、Button、Radix Select、颜色变量、24px 页面边距和页面标题规范。
- 支持独立文档标题、正文、三级正文标题、基本文字样式、正文目录、剪贴板图片、自动保存、草稿恢复、冲突提示和只读访问。
- 使用固定版本 Tiptap 3.32.0，沿用现有 DocumentBody、版本检查和 MinIO 资源 API；没有新增后端接口或数据库迁移。
- 此样板只接受能完整转换的正文、标题和内部图片。表格、绘图等其他块以及未支持的颜色、对齐、图片说明、外链图片等会明确拒绝打开，原内容不会提交覆盖。
- 本地体验文档：`http://127.0.0.1:5179/flowcraft/documents/5683f0dc-2026-42a0-b0e9-8ffa47155763/sample`。已在应用内浏览器实际粘贴截图、继续输入中文、确认保存并刷新查看。

Node 20.19.5，本地 API 3801、Vite 5179、隔离测试数据库与 MinIO。

- `npm --prefix client test`：16 个文件、43 项通过。
- `npm --prefix client run test:e2e`：18 条通过，包含原文档、绘图、权限、历史、导出、恢复和新增样板。
- 最后界面微调后再次执行 `test:e2e -- tiptapSample.spec.ts`：3 条通过。
- `npm --prefix client run build`：类型检查与构建通过；保留原有大分块提示。
- `git diff --check`：通过。

新增浏览器流程使用真实 ClipboardItem PNG 与粘贴快捷键，覆盖光标处插图、继续输入、MinIO 上传、无 blob/data URL 的持久化内容、刷新、新浏览上下文、只读账号、503 上传失败与原文件重试，以及上传期间撤销后恢复图片。刷新只读正文不会触发多余 PATCH。

## 独立评审与修正

独立评审仅检查本次样板改动，发现两项重要问题，均先增加失败用例，再修复并通过回归：

1. 上传完成的属性事务曾进入撤销历史；上传期间删除再恢复也会丢失资源关联。完成上传的事务现已排除撤销历史，并按块 ID 保留完成的资源映射，恢复图片时重新关联。
2. 初始适配器会丢弃旧文档的部分属性和外链图片。现已严格拒绝不能完整转换的块、属性及图片来源。

额外验证并修复粘贴后继续打字替换图片的问题，以及设置编辑权限时产生无意义保存的问题。
