# 正式文档编辑页 Tiptap 3 迁移验证

日期：2026-10-23。范围为当前本地开发分支，未访问或更新线上。

## 最终行为

- 文档中心创建、列表打开、阅读模式、正文编辑和历史版本预览统一使用 Tiptap 3.32.0。
- 保留原文档 URL、DocumentBody 格式、块 ID、属性、嵌套、样式、表格、附件、文档链接和 Excalidraw 引用，不进行数据库迁移。
- 截图可通过系统剪贴板直接粘贴。先显示本地预览，再上传隔离 MinIO，完成后自动保存稳定资源引用。
- 沿用原保存队列、版本冲突检查、离线草稿、失败重试和权限。上传失败的图片可删除后继续保存，也可撤销删除后找回原文件并重试；复制待传图片后，重试会更新所有副本。
- 历史正文和已被当前版本删除的图片、附件使用各自历史版本的授权上下文读取；恢复生成新版本，共享绘图仍遵循原引用规则。
- 原样板入口从文档中心移除。`/documents/:id/sample` 跳转 `/documents/:id`，`/documents/sample` 跳转文档中心。
- 沿用原 Sidebar、Topbar、右侧 AI 和 UI 组件。页面标题 24px、操作控件 13px/36px、原有页面边距，正文编辑字号 15px。切换文档与绘图不自动关闭 AI。
- 移除旧 BlockNote React/Ariakit 编辑界面依赖；Markdown 导入暂留原核心解析器，正式编辑器不加载它。
- 后端拒绝持久化 pending、blob、data 临时资源地址，避免出现“已保存”但刷新后失效的引用。

## 独立评审与修复

评审针对本次迁移的全部未提交修改，未重复评审旧分支。

1. 整块剪切/复制的原生 HTML 编解码会丢资源与块类型：增加受控 JSON 属性，在编辑器序列化和实际 DOM 中同时保留资源及块元数据，并确保正文键盘和剪贴板事件交给编辑器处理。真实浏览器复制、重试上传、刷新验证通过。
2. 选区后 Enter 未替换选中文字：先在同一事务删除选区，再按文档结构拆块，真实 Editor 回归由失败转通过。
3. 文本转代码块会丢链接的显示文字：改用递归提取正文，真实浏览器回归由失败转通过。

补充修复失败上传删除/撤销与待传图片副本的关联；相关用例均先复现失败。后端保存边界也有先失败后通过的测试。

评审提到但不扩展四级以上标题：现有后端文档契约只接受 1/2/3 级，继续遵守现有约束。未进行多人实时协作、云服务接入或线上部署。

## 编辑体验补充（2026-10-23）

- 文档与绘图编辑页移除面包屑，原位置提供返回列表入口；内嵌绘图提供返回文档入口，并沿用未保存内容保护。

- 输入标题、无序/有序列表、待办、引用、代码围栏、分隔线和行内标记即时排版。代码围栏、分隔线支持回车。转换沿用原块 ID 和保存流程。
