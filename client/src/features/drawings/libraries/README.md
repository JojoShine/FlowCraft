# Complete common Excalidraw libraries

Whole, unabridged library packs from the official Excalidraw community catalog, downloaded on 2026-10-23. MIT license is retained in LICENSE. No runtime third-party downloads.

Basic packs (82 items) are preloaded; cloud/Kubernetes/DevOps packs load from local bundled chunks on demand. The picker can also load all 676 items. Older nonempty libraries gain only the newly added common packs; custom items and removals from the original packs remain intact. An explicitly empty library stays empty.
